# e(Phi)Lab — versión 0.1

Plataforma modular en Streamlit para experimentación, modelado y análisis de datos STEM.

## Módulo inicial

**e(Phi)Kart**: entorno digital para estudiar el movimiento de un carrito impulsado por energía elástica.

## Alcance de la versión 0.1

- Identidad visual basada en el azul institucional ESPOL.
- Navegación multipágina.
- Página principal de e(Phi)Lab.
- Portada del módulo e(Phi)Kart.
- Páginas internas preparadas como módulos funcionales.
- Arquitectura lista para incorporar sliders, barras dinámicas, gráficas y velocímetro en la versión 0.2.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Despliegue en Streamlit Community Cloud

1. Subir este proyecto a un repositorio de GitHub.
2. En Streamlit Community Cloud seleccionar el repositorio.
3. Definir `app.py` como archivo principal.
4. Desplegar.
